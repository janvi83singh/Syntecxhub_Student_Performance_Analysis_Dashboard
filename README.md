# 🎓 Student Performance Analysis Dashboard

An interactive **Student Performance Analysis Dashboard** developed using **Microsoft Power BI** to analyze student academic performance based on mathematics, reading, and writing scores along with demographic and educational factors.

The dashboard transforms student performance data into meaningful visual insights through interactive KPIs, charts, filters, and comparative analysis.

---

## 📌 Project Overview

The **Student Performance Analysis Dashboard** provides an interactive overview of the academic performance of students.

The dashboard analyzes:

* Student scores
* Mathematics performance
* Reading performance
* Writing performance
* Overall score percentage
* Gender
* Ethnicity
* Parental education
* Test preparation
* Top-performing students

The dashboard is designed to help identify patterns and relationships between student performance and different demographic and educational factors.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze overall student performance.
* Calculate average mathematics, reading, and writing scores.
* Compare performance across different ethnic groups.
* Analyze performance based on gender.
* Study the impact of parental education.
* Analyze the effect of test preparation.
* Identify the top-performing students.
* Create meaningful KPIs for student performance.
* Build an interactive and user-friendly Power BI dashboard.
* Generate insights that can support academic decision-making.

# 📈 Dashboard Features

## 1. Student Performance KPIs

The top section provides a quick overview of:

* Total number of students
* Average Mathematics score
* Average Writing score
* Average Reading score
* Average overall score percentage

These KPIs allow users to understand the overall academic performance at a glance.

---

## 2. Performance by Ethnicity

A bar chart compares the **average score percentage across different ethnic groups**.

This helps identify differences in average academic performance between groups.

---

## 3. Performance by Gender

A donut chart displays the average score percentage based on:

* Female
* Male

This provides a simple comparison of academic performance by gender.

---

## 4. Performance by Parental Education

The dashboard analyzes the relationship between **parental education level and student performance**.

The visualization includes education levels such as:

* Bachelor's Degree
* Master's Degree
* High School
* Some College
* Some High School
* Associate's Degree

This can help explore whether parental education is associated with differences in student performance.

---

## 5. Test Preparation Analysis

A donut chart compares students who:

* Completed test preparation
* Did not complete test preparation

This helps analyze the relationship between test preparation and academic performance.

---

## 6. Ethnicity & Parental Education Analysis

The dashboard includes a detailed visualization comparing:

**Ethnicity + Parental Education + Average Score Percentage**

This allows users to explore multiple dimensions of student performance simultaneously.

---

## 7. Top 5 Students by Performance

The dashboard identifies the **Top 5 students based on performance**.

The comparison includes:

* Mathematics score
* Reading score
* Writing score

This makes it easier to identify high-performing students.

---

# 🎛️ Interactive Filters

The dashboard contains interactive slicers that allow users to filter the analysis by:

* **Ethnicity**
* **Gender**
* **Parental Education**
* **Test Preparation**

When a filter is selected, the dashboard visuals dynamically update according to the selected criteria.
